---
title: ヘビ
description: レトロなARGVUS端末のスネークゲームをプレイしてください。
---
以下でゲームを開く:

```sh
argvus game-snake
```
ゲームを開いたら、`Enter` を押して右に移動を開始するか、`h`、`j`、`k` または `l` を押してその方向にすぐに開始します。アプリケーションメニューには `ARGVUS Snake` ランチャーも含まれています。

ランチャーは、標準の ARGVUS Kitty プロファイルを通してゲームを開き、コントロールセンターに合わせたサイズ `1380x840` の中央浮動ウィンドウで表示します。

`argvus-game-snake` はピクセルスタイルのターミナルゲームです。移動は意図的に標準の Vi キーを使用します:

- `h`: 左;
- `j`: 下;
- `k`: 上;
- `l`: 右.

ヘビは食べ物を食べると成長します。壁や自分の体に触れるとラウンドが終了します。`p` またはスペースで一時停止、`r` でゲームオーバー後に再開、`q` または Esc で終了します。

ローカルのトップ10ランキングは `$XDG_CONFIG_HOME/argvus/games/snake/ranking.json` またはデフォルトでは `~/.config/argvus/games/snake/ranking.json` に保存されます。パッケージのインストールはホームディレクトリにファイルを作成しません。
